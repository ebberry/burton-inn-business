# The Burton Inn: Business Documents

Private working repo for running and reopening the Burton Inn
(24007 Vashon Hwy SW, Vashon, WA 98070). The public website lives in a
separate repo (`burton-inn`) and is published by Netlify; nothing here is published.

| Folder | What's in it |
|---|---|
| [permitting/](permitting/) | Permits and licenses for reopening: research, tracker workbook, applications, records, correspondence, issued permits. Start with [permitting/PROCESS.md](permitting/PROCESS.md). |

| [entity/](entity/) | The LLC: formation documents, UBI, annual report date. |

Add new top-level folders as other areas come up, for example `lease/`, operating agreement in `entity/`,
`insurance/`, `finance/`, `partners/`.

## Conventions

- File names: `YYYY-MM-DD_party_short-description.ext`, so files sort by date.
- Each folder gets a short `README.md` saying what belongs there.
- Keep the repo private. Some of what lands here (lease, financing, background-check
  paperwork) should never be shared publicly.
