# Burton Inn: Permitting and Licensing

Working folder for reopening the Burton Inn (24007 Vashon Hwy SW, Vashon, WA 98070,
unincorporated King County). Everything generated along the way lives here:
research, the tracking workbook, applications, records, letters and issued permits.

**Start with [PROCESS.md](PROCESS.md).** It is the step-by-step walkthrough.

## Layout

| Path | What goes there |
|---|---|
| [PROCESS.md](PROCESS.md) | The walkthrough: phases, steps and checkboxes, in order |
| [decisions.md](decisions.md) | Decisions only the owner can make, and what was decided |
| [contacts.md](contacts.md) | Agencies, portals and people |
| [log.md](log.md) | Dated running log: what was filed, who called, what changed |
| [workbook/](workbook/) | `Burton_Inn_Permitting_Workbook.xlsx`, the master tracker (status, schedule, costs) |
| [research/](research/) | Research write-ups and their sources, one file per pass, dated |
| [records/](records/) | Records requests sent and the records that come back |
| [applications/](applications/) | Drafts and submitted copies of every application |
| [correspondence/](correspondence/) | Emails, letters and call notes with agencies, landlord, contractors |
| [permits/](permits/) | Issued permits, licenses, approval letters, inspection results |

## Conventions

- **File names:** `YYYY-MM-DD_agency_short-description.ext`, for example
  `2026-11-03_kc-dls_zoning-letter-request.pdf`. Dates sort, agencies group.
- **Agency short names:** `kc-dls` (King County Local Services / Permitting),
  `kc-fire` (King County Fire Marshal), `phskc` (Public Health Seattle and King County),
  `lcb` (Liquor and Cannabis Board), `dor` (Dept. of Revenue / Business Licensing),
  `li` (Labor and Industries), `burton-water`, `landlord`.
- **Item numbers:** `#1` to `#20` refer to rows in the workbook's Master List tab
  (also Tab 1 of the research file). Use them in file names and log entries when it helps,
  for example `2026-11-10_phskc_7-plan-review-application.pdf`.
- **Status lives in the workbook.** When something moves, update the Master List status,
  tick the box in PROCESS.md, and add a line to log.md.
- **New research** gets a new dated file in `research/`; don't overwrite the old one.

This folder is planning material, not legal advice. Confirm with LCB, King County DLS
and Public Health.
